# Robot Pickup Line Championship

One line, at most 200 characters: the funniest pickup line a robot could use. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
